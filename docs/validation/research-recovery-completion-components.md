Existing prefix/completion validators remain unchanged.
- [Tests](research-recovery-completion-components.test.mjs) regenerate exact bytes, reseal semantic mutations, exercise stipulated relation/retry/width helpers, and pin literal statuses, versions, digests and measurements.

The immutable source fields identify the original run/bootstrap, research plan,
approval, reservation, frozen assignment P, allocation, attachment and parent/child
runtime histories. The current input is revision 3, retaining its original
revision-2 assessment provenance and report. New snapshots are constructed from
these fields; a later row is not copied and relabelled as a prior state. No stored
maximum elects an owner. Every prior artifact byte is preserved.

Each alternative has its own original source/outcome labels. Repeated TaskKey,
PlanRef and recovery/completion identities across examples do not coexist in one
store; one must not merge these alternatives or publish them over existing rows.
The raw input SHA-256 values fingerprint documentation bytes. CommitRef changeDigest
hashes explicitly unqualified labels, never actual storage commitments.

Original turn/result/native authenticity, actual source participation, complete
current/historical membership, currentness, Main authority/context, native object
ownership/quiescence, direct proofs, H/C and complete atomic effects remain
**stipulated and unqualified**. A label, body digest, matching snapshot or reference
list cannot authenticate those facts. This packet adds no wire decoder, complete
transaction read set, profile/header/manifest/row/change hash, database, runtime
module, model/native call, adapter, migration or executable product plan.
