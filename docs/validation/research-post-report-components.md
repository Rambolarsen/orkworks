## Original retry and semantic denials

The report retry oracle checks supplied current child authority, runtime/run
closure, rate, scope/owner/currentness, source/membership and committed-original
proof before lookup. It verifies original descriptor/request digests, stream,
receipt key/operation/CAS/expected head/closed response/C and original head
before-image correspondence. That head is an original-outcome component, not
today's mutable head. A fixture-only map binds requestDigest to supplied original
C; it is not a storage proof. Identical requests return their original response
despite later live versions and create no input/summary/version/write. Altered
requests/receipt fields, revoked/unknown facts or missing outcome correspondence
deny. The checker is not a wire decoder, authenticated handler or current-store
lookup and supplies no whole outcome proof.

Main rejection retry uses its **different** current-authority premises and exact
original request/outcome. It returns original run receipt 21 or 22 and its actual
paired completion, never a later child-report run version/input. No live completion
predicate or case label elects a missing original companion. A report retry cannot
reuse Main authority to bypass child closure.

Input/request mutations are resealed and remeasured before finite validation.
Denials cover restored pending B, missing original disposition/companion/assessment,
false-collector misclassification, retargeted collection/reservation, terminal or
wrong runtime, frozen CAS, child-authored assessment, B-source input rollback,
missing configuration/prior-plan, A/B scope conflation, wrong event producer,
task/result/plan/summary history rewrite, stale pointer retention, high-water
increment, unchanged-selector rewrite, extra role/counter increments, lost
blockers, invented ordinary revisions and altered original receipt/response.
