# Retained child reviewer source-byte component packet

Tracking: [#1183](https://github.com/Rambolarsen/orkworks/issues/1183), fed by the
accepted [child review source preparation](../superpowers/specs/2026-10-31-child-review-source-preparation-design.md#owner-acceptance-and-bounded-component-handoff--2026-11-02)
choices and the
[qualification handoff](../superpowers/plans/2026-10-31-child-review-source-qualification.md#gate-b--bounded-component-codecs-and-source-ownership)
Gate B. This packet pins the accepted selected child source bytes — configuration
leaves/rendering, retained review-input snapshot, single-task plan, approval
request/source/receipt, reservation, allocation, attachment and child assignment
source joins.

- `generate-child-review-source-vectors.py` — independent canonical byte/digest
  generation for [child-review-source-vectors.json](child-review-source-vectors.json).
- `child-review-source-components.mjs` — structural strict checker; exports
  per-record validators and the composite `verifyChildChain` that performs the
  exact plan/configuration/approval/reservation/allocation/attachment/source joins.
- `child-review-source-components.test.mjs` — vector and rejection assay.

  evidence this byte packet cannot supply.
- [ ] Native authority fences, complete fresh preparation/publication witnesses
  (Gate C) and executable qualification (Gate D) remain separate.

## Boundary

Every constructed identity, outcome, storage commit and capability check is
synthetic and labeled unverified (`classification:
synthetic-unverified-source-bytes-only`). The packet never claims complete fresh
state, native object identity, source-event participation, SQL atomicity, an
eligible adapter, coding-tool role profile or authority. Canonical records reuse
the accepted #741 serializer conventions; child leaf substitutions, delivery
order and retained-input framing follow the accepted Gate A choices. The input
snapshot's `task` is the reviewer's own task key (the input belongs to that
task's plan and delivery); the target worker assignment rides `target`/`result`.
Whether that task-key reading is the owner's intent remains owner-reconciliation
pending; child event/state semantics stay unqualified in Gate B.

## Reproduce with Node

```bash
python3 docs/validation/generate-child-review-source-vectors.py
node --test docs/validation/child-review-source-components.test.mjs
```

The generator rewrites the vector catalog; the test survives on vectors only and
opens no database, network connection or model/runtime session. The checker
re-derives every canonical byte and digest with Node built-ins and reuses the
accepted root run, provenance/executable, research-report and evidence-source
component validators for shared shapes; no database or runtime opens.
