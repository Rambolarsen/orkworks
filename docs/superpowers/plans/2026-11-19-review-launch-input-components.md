# Offline ordinary-review launch-input components

Outcome: exact candidate proposal/prepared bytes and independent digest vectors
agree; malformed, substituted or oversized inputs are denied. This validates
logical values and joins only. It does not qualify a producer, complete effective
catalog/integration leaf inputs, live source custody, physical persistence or Start.

Contract: [typed proposal and prepared input](../specs/2026-11-19-review-launch-input-design.md).
Tracking: [#68](https://github.com/Rambolarsen/orkworks/issues/68),
[#66](https://github.com/Rambolarsen/orkworks/issues/66),
[#1899](https://github.com/Rambolarsen/orkworks/issues/1899).
Status: owner accepted this plan and source/profile/byte choices on 2026-11-19
with “keep going”. Implementation evidence is in the
[component report](../../validation/ordinary-review-launch-input-components.md). Earlier #1913/#1919 acceptance remains intact.

## Boundaries

Only new docs/validation Node 22 standard-library artifacts and registration in
`docs/package.json`. No Rust, Electron, production API/import, model/native call,
application metadata, migration, background observer or new dependency. Existing
#1919 component/test/vector bytes remain unchanged. No ordinary recommendation
variant or role capability becomes enabled.

## Delivery and acceptance

### 1. Closed proposal and canonical bytes

Create `docs/validation/ordinary-review-launch-input-components.mjs`, its
`.test.mjs` and `ordinary-review-launch-input-vectors.json`. Follow TDD inline.

- [x] Literal proposal/prepared values and expected complete canonical byte
  strings in vectors; independently computed golden SHA-256 with the exact
  domain separator, not generated by the implementation encoder under test.
- [x] Test closed fields/domains, UUID/counter maxima and overflow, chain depth,
  explicit user-request kind implicit in the closed request schema, complete
  source runtime/lifecycle/Git tuple, exact design/implementation slot, strict
  configuration profile and selected-draft joins.
- [x] Unicode scalar/non-BMP/CRLF/tab cases, no normalization, malformed UTF-8,
  lone surrogates, controls, duplicate/escaped/reordered keys, sparse arrays and
  alternative representations. No lossy native-path decoding.
- [x] Exact per-field/full proposal/configuration/prepared/request byte bounds;
  include valid boundary constructors only where reachable and an explicit
  complete byte recount for those closed values. Total caps win over individual
  maxima; no truncation. Future cache/view/response codecs and complete 64 KiB
  entry/response witnesses are outside this slice, not invented synthetic padding.

Pass: focused `node --test docs/validation/ordinary-review-launch-input-components.test.mjs`
under Node22 goes RED then GREEN with literal bytes/digests. Maximum-width cases
report what was actually constructed, not an invented valid maximum.

### 2. Frozen input joins and mutation controls

- [x] Pure join validator consumes synthetic owned-entry facts: original or
  explicit edited draft, proposal/runtime/source IDs and revisions, canonical
  location, captured artifact and configuration. Missing/unknown facts deny;
  no default true/current, fallback or unqualified hash grants eligibility.
- [x] Independently mutate every prepared field (and nested launch-affecting
  value); encoding/digest changes for valid mutations, validation denies illegal
  ones. Same visible text with changed owner/revision or preview remains distinct.
- [x] Exact selected draft drives configuration tool/model and instruction; a
  changed draft after inspection, mixed proposal, replaced runtime, cwd mismatch,
  renamed capture owner, substituted design/implementation slot, changed pin/
  epoch/configuration, changed Git common-directory/head or expired entry denies.
- [x] Simulated owner-reference predicates are labeled as assumptions, not
  actual Store/runtime/configuration custody. Test reverse source/admission
  orders as logical comparisons only, with no physical/concurrency claim.
- [x] Meaningful temporary-copy mutations remove canonical equality, nested
  source/configuration/draft joins, full digest inclusion and full-prepared-value byte
  charge; existing negative tests must fail, then restore/delete those copies.

Pass: all joins have independent expected dispositions and byte accounting;
no native provider/process or application filesystem effect is used.
